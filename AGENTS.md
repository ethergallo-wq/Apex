# Animaldex Project Knowledge

- Non eseguire mai il push al posto dell'utente. L'utente vuole sempre fare il push dal proprio terminale.
- Alla fine di ogni modifica, fornisci il comando terminale per pushare e specifica chiaramente cosa e' stato modificato.
- Se ci sono molte modifiche non correlate nel working tree, suggerisci comandi che aggiungano solo i file toccati da Codex.
